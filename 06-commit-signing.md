# Commit Signing

Commit signing, bir Git commit'inin gerçekten belirtilen geliştirici tarafından oluşturulduğunu doğrulamaya yardımcı olan bir yöntemdir.

Normal bir Git commit'inde kullanıcı adı ve e-posta bilgileri bulunur ancak bu bilgiler tek başına güçlü bir kimlik doğrulama yöntemi değildir.

Signed commit kullanıldığında commit kriptografik olarak imzalanabilir.

GitHub doğrulanmış imzaları "Verified" etiketiyle gösterebilir.

Commit signing özellikle:

- Commit kaynağını doğrulamak
- Sahte commit riskini azaltmak
- Yazılım tedarik zinciri güvenliğini artırmak

amacıyla kullanılabilir.
