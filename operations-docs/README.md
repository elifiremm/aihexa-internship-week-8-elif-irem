# Operations Documentation

Bu klasör, uygulamanın operasyon ve devir dokümantasyonunu içerir.

## Dokümanlar

- architecture.md → Sistem mimarisi ve temel bileşenler
- api.md → API endpoint bilgileri
- database-config.md → Veritabanı ve yapılandırma bilgileri
- runbook.md → Sistemin çalıştırılması ve operasyon adımları
- troubleshooting.md → Sık karşılaşılan sorunlar ve çözüm yöntemleri
- known-issues.md → Bilinen sorunlar

## Amaç

Bu dokümantasyonun amacı, projeyi devralan bir geliştiricinin sistemin
mimarisini, çalışma şeklini ve temel operasyon süreçlerini hızlı bir şekilde
anlayabilmesini sağlamaktır.
