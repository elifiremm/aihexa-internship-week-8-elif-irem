# Troubleshooting

## Uygulama başlamıyor

Kontrol edilmesi gerekenler:

- Gerekli bağımlılıklar kurulmuş mu?
- Kullanılan port başka bir uygulama tarafından kullanılıyor mu?
- Environment değişkenleri doğru mu?

## Database bağlantısı başarısız

Kontrol edilmesi gerekenler:

- Database servisi çalışıyor mu?
- Host ve port doğru mu?
- Kullanıcı bilgileri doğru mu?
- Database mevcut mu?

## API cevap vermiyor

Kontrol edilmesi gerekenler:

- Backend çalışıyor mu?
- Endpoint doğru mu?
- HTTP metodu doğru mu?
- Loglarda hata bulunuyor mu?

## Port kullanımda

Uygulamanın kullandığı port başka bir süreç tarafından kullanılıyorsa
ilgili süreç kapatılabilir veya uygulamanın portu değiştirilebilir.
